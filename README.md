# صحوة

موقع صحوة ومساحة الفريق، مبنيان بـ **Next.js App Router** وReact، مع **PostgreSQL على Neon**. ألوان صحوة والخطوط والمكونات البصرية ومحتوى الصفحة الرئيسية محفوظة.

## مساحة الفريق

- `/team`: الأدوات المتاحة لحسابك.
- `/team/guide`: دليل صحوة؛ يعرض الهيكل التفاعلي والتفاصيل الكاملة لكل مسؤولية كما وردت في المسودة التنظيمية الجديدة، بما فيها المهام الخاصة بمسؤولة قطاع الطالبات وبقية مسؤولات الطالبات، وقواعد اتخاذ القرار والفعاليات والتقارير والبرامج العلمية. الوحدات غير المفعّلة والقرارات المقترحة تظل مميزة بوضوح.
- `/team/events`: سجل الفعاليات للمسؤولين. اسم الفعالية هو الحقل الإلزامي الوحيد؛ التاريخ والمسؤول وعدد الحضور والملاحظات اختيارية. يُختار المسؤول من سجل المتطوعين.
- `/team/volunteers`: سجل مستقل للمتطوعين. الاسم والجامعة والحالة و«شاب أو بنت» إلزامية، وباقي البيانات اختيارية. يظهر العمر المحسوب تلقائيًا عند إدخال تاريخ الميلاد.
- `/team/files` و`/team/forms`: الروابط الحالية للملفات والنماذج.
- `/studio`: الاستوديو الحالي وقوالبه ومحرره، مع الحفاظ على مسودة المحرر أثناء التنقل.

الدخول متاح حاليًا للمسؤولين فقط من خلال حساب صحوة الأساسي. سجلات المتطوعين ليست حسابات دخول، ولا يوجد إنشاء بريد أو كلمة مرور للمتطوع. صفحة إدارة الحسابات أزيلت إلى أن تُعاد الصلاحيات الفردية في مرحلة لاحقة.

ملحق تكافؤ الأدوار بين الشباب والطالبات محفوظ في `docs/sahwa-role-parity.md`، ويوضح الاستكمال التفصيلي للأدوار المتناظرة من دون إنشاء صلاحيات مؤسسية غير معتمدة.

الوثيقة المرجعية الكاملة للهيكل والصلاحيات محفوظة في `docs/sahwa-governance.md`، وتعرضها المنصة من بيانات `src/data/sahwaGovernance.ts`. لا توجد في الهيكل الحالي قيادة مستقلة باسم «مسؤول الإعلام الميداني»؛ يتبع عضو الإعلام الميداني للإعلام المركزي. هذه المسودة لا تصبح سياسة ملزمة قبل اعتماد البنود التي تتطلب قرارًا مؤسسيًا.

## التشغيل

```sh
npm ci
# Configure .env.local using .env.example, with development-only secrets.
npm run db:migrate
npm run dev
```

متغيرات الخادم:

- `DATABASE_URL`: اتصال Neon المجمّع لتشغيل التطبيق.
- `DATABASE_URL_UNPOOLED`: الاتصال المباشر للترحيلات.
- `SAHWA_SESSION_SECRET`: قيمة عشوائية بطول 32 حرفًا على الأقل.
- `SAHWA_ACCOUNT_EMAIL` و`SAHWA_PASSWORD_HASH`: البريد وتجزئة كلمة المرور لحساب صحوة الأساسي المشترك بين المسؤولين.

لا تضع القيم في Git أو متغيرات `NEXT_PUBLIC_`. في ملفات `.env.local` الخاصة بـNext.js اهرب كل علامة `$` في تجزئة كلمة المرور إلى `\$` لمنع تمدد متغيرات dotenv. في إعدادات Vercel تحفظ التجزئة الأصلية دون إضافة الشرطات.

## إعداد قاعدة البيانات والنشر

مشروع Neon: `delicate-poetry-14573010`، وقاعدة البيانات `neondb`. ترحيلات SQL محفوظة في `db/migrations`، ويمكن إعادة تشغيلها. لا ينفذ البناء ترحيلات تلقائيًا.

1. اختبر الترحيل على فرع Neon منفصل، واتصل به في Preview فقط.
2. بعد نجاح الاختبارات، نفّذ نفس الترحيل على production بالاتصال المباشر.
3. أضف اتصال production إلى `DATABASE_URL` في Vercel ضمن Production فقط، ثم انشر Next.js.
4. ادخل ببيانات حساب صحوة الأساسي المحددة في متغيرات الخادم.
5. أضف المتطوعين كسجلات مستقلة من صفحة «المتطوعون». لا تنشأ لهم حسابات دخول في المرحلة الحالية.

حساب Vercel الحالي ومشروع `sahwa` مستمران. قواعد إعادة كتابة Vite القديمة أزيلت لأن Next.js يدير الصفحات وواجهات API الآن. لا توجد صفحة تسجيل حساب عامة.

## حماية الدخول

كلمة مرور حساب صحوة محفوظة كتجزئة scrypt ولا تحفظ بصورتها الأصلية. رموز الجلسات عشوائية وتخزن في قاعدة البيانات كـHMAC فقط؛ cookie من نوع HttpOnly وSecure وSameSite على النشر، ولمدة 30 يومًا مع «تذكرني»، أو 24 ساعة دونها. الخروج يلغي الجلسة في الخادم، وتغيير البريد أو تجزئة كلمة المرور يلغي الجلسات القديمة تلقائيًا. كل طلب خاص بمساحة الفريق يتحقق من جلسة حساب صحوة في الخادم.

عمليات التعديل تتحقق من Origin ومن رقم مراجعة السجل. عداد محاولات الدخول مشترك في قاعدة البيانات: 10 محاولات للبريد و50 لعنوان الاتصال خلال 15 دقيقة، دون كشف صحة البريد.

## التحقق

```sh
npm run typecheck
npm test
npm run build
```

اختبارات الدخول والسجل تستخدم محرك PostgreSQL مدمجًا عبر PGlite. تشمل قصر الدخول على حساب صحوة الأساسي، رفض الحسابات الفردية القديمة، التحقق من بيانات المتطوعين والفعاليات، تعارض التعديلات، الجلسات، وحقول النماذج. اختبارات الاستوديو والمكتبة محفوظة ومحدّثة لـReact 19.

## الصفحات العامة

الرئيسية والجامعات والتواصل كما هي. المكتبة تظل تحت مفتاحها الحالي (`library: false`)؛ لم تُفعّل ضمن هذا التغيير. مواد الاستوديو العامة لا تحتوي بيانات المتطوعين. صلاحيات Google Drive وGoogle Forms مستقلة عن حسابات الموقع.
